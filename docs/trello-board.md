### Title screen
_labels: Demo 1; last activity 2020-05-25_

Title screen:
- Main title screen just has ship and stellar swing title
- Pressing a button causes it to animate and now there's space at the bottom for a menu. the menu says new game/continue/options/exit
- Pressing options pops up an options menu over the top, with warnings for closing it if settings are changed
- Pressing new game or continue pops up a file select
- Pressing exit (or escape) pops up a confirmation to exit
- Selecting a new file asks you if you want to enable the tutorial or not (later configurable from the settings) and loads the first level
- Selecting an existing file just shows the level selection directly
